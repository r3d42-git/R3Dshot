# R3Dshot 0.2.0

## Deutsch

Der Editor erhält eine übersichtlichere Oberfläche mit Werkzeugen links,
Eigenschaften rechts und einem etwas helleren Dunkelblau bis in die Titelleiste.

- Alle zwölf Werkzeuge sind in vier Gruppen erreichbar. Farbe, Linienstärke,
  Text und weitere Vorgaben lassen sich schon vor dem Zeichnen einstellen.
- Beschriftete Aktionen für Bild kopieren und Sichern sowie kurze
  Erfolgsrückmeldungen erleichtern den Abschluss der Bearbeitung.
- Die Statuszeile zeigt Bildgröße und Zoom. „Anpassen“ und „100 %“ sind getrennt;
  bei 100 % entspricht ein Bildpixel einem physischen Displaypixel.
- Tastaturbefehle berücksichtigen den Fokus von Texteingaben. Ein Klick auf die
  Arbeitsfläche gibt die Befehle wieder an die Bildbearbeitung zurück.
- Der sichtbare Auswahlcursor wechselt nach einem Aufnahmebefehl wie Print
  zuverlässig zum Fadenkreuz. Die Fokuswiederherstellung bleibt begrenzt.
- Ein Darstellungsfehler beim Wechsel zwischen Hell und Dunkel ist behoben.

Modell-/Renderer-, Editor-Workflow- und native Auswahltests bestanden. Die
Oberfläche wurde in Hell und Dunkel, bei kleiner Fenstergröße sowie mit
Zeichenwerkzeugen, Texteingabe, Undo/Redo und Zoom geprüft und anschließend vom
Nutzer im lokalen Einsatz bestätigt. Ein Start auf einem frischen Mac und
physische Mehrdisplay-Wechsel wurden nicht separat geprüft.

Für Apple Silicon (arm64), macOS 15.2 oder neuer. App und DMG werden mit
Developer ID signiert, von Apple notarisiert und mit angehefteten Tickets
ausgeliefert. Die Bearbeitung bleibt lokal und nicht-destruktiv.

## English

The editor gains a clearer layout with tools on the left, properties on the
right, and a lighter dark-blue appearance extending into the title bar.

- All twelve tools are arranged in four groups. Set colors, stroke widths,
  text, and other defaults before drawing.
- Labeled Copy Image and Save actions provide brief success feedback.
- The status bar displays image dimensions and zoom. Fit and 100% are separate;
  at 100%, one image pixel corresponds to one physical display pixel.
- Keyboard commands respect text-entry focus. Clicking the canvas returns
  commands to image editing.
- Starting capture with a command such as Print now reliably changes the
  visible pointer to a crosshair, while focus recovery remains bounded.
- Fixed an image-display issue when switching between light and dark modes.

Document/renderer, editor workflow, and native capture-selection tests passed.
The interface was checked in light and dark modes, at a small window size, and
with drawing, text entry, undo/redo, and zoom, followed by user confirmation in
local use. A clean-machine launch and physical multi-display transitions were
not separately tested.

For Apple Silicon (arm64), macOS 15.2 or later. Both app and DMG are Developer ID
signed, notarized by Apple, and delivered with stapled tickets. Editing remains
local and non-destructive.
