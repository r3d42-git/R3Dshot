# R3Dshot 0.1.0

Erste veröffentlichte Fassung von R3Dshot, einem nativen Screenshot-Werkzeug für Apple-Silicon-Macs mit macOS 15.2 oder neuer.

- Menüleisten-Workflow mit globalen Tastenkürzeln für Bereichs-, Fenster- und Bildschirmaufnahmen.
- Nicht-destruktiver Editor mit Formen, Text, Sprechblasen, Markern, Schrittmarkierungen, Pixelierung, Fokus und Zuschneiden.
- PNG-Export, Zwischenablage und Quick Action.
- Die App fordert ausschließlich die macOS-Berechtigung für Bildschirmaufnahme an; sie überträgt keine Aufnahmen.

Das DMG enthält R3Dshot, einen Programme-Ordner-Alias und die GPL-3.0-or-later-Lizenz. Nach dem Öffnen R3Dshot in den Programme-Ordner ziehen.
