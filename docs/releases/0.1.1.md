# R3Dshot 0.1.1

Dieses Wartungsrelease verwendet das neue G2-Developer-ID-Zertifikat von Team G6JH37W285. Die App-Funktionen bleiben gegenüber 0.1.0 unverändert.

Die vorangegangene macOS-27-Prüfung des Quellstands bestätigte Build, Modell-/Renderer-Test, Start und Signatur. Aufnahme, Hotkeys und Editor wurden vom Nutzer unter macOS 27 ohne Auffälligkeiten geprüft. Das ist keine erneute UI-Abnahme des hier ausgelieferten Builds; weitere Display- und Berechtigungsszenarien wurden dabei nicht einzeln geprüft.

Das DMG ist für Apple-Silicon-Macs mit macOS 15.2 oder neuer bestimmt.
